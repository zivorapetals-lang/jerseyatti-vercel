# Jersey Atti website

Static site (HTML, CSS, JS). No build step.

- `index.html`  page content
- `css/style.css`  all styles (colours are variables at the top, in `:root`)
- `js/main.js`  intro, shop, customiser, animations
- `assets/`  photos and logo (replace with HD originals, keep the same file names)

## Deploy on Vercel
1. `npm i -g vercel`
2. Open a terminal in this folder and run `vercel`, then `vercel --prod`

Or push this folder to GitHub, then Vercel > Add New > Project > Import > Deploy.
